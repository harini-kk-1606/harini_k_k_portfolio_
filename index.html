Biomedical · Embedded

VEGA-Based Cardiovascular Signal Analysis System

The problem

Heart health is usually checked with bulky clinical equipment. Pulse Transit Time (PTT), the delay between the heart's electrical beat and the pulse reaching the fingertip, can be measured with small, low-cost sensors.

How it works

  1. ECG and PPG sensors capture the heartbeat and blood-volume pulse together
  2. Firmware on the VEGA Aries V2 RISC-V board samples both in real time
  3. Processing logic matches each beat and computes the PTT
  4. An OLED display shows the readings live

What I built

Modular embedded C firmware for signal acquisition and processing, the PTT computation, and validation of the full system on VEGA Aries V2 with a real-time OLED interface.

  • Embedded C
  • VEGA Aries V2
  • RISC-V
  • ECG
  • PPG
  • Signal Processing
  • OLED
Transport · IoT

Distributed Sensor-Fused Adaptive Boarding Control for Railway Coaches

The problem

Crowded platforms lead to overfilled coaches, uneven passenger distribution and unsafe boarding, while doors stay open for a fixed time whether a coach is empty or full.

How it works

  1. Passengers authenticate at the door with QR codes or RFID
  2. Load sensors measure occupancy; the system predicts throughput
  3. A sensor-fusion algorithm decides admission and door dwell time
  4. Signals guide passengers to coaches with space; interlocks keep doors safe

What I built

The system design, the adaptive multi-sensor decision algorithm that regulates occupancy, balances passengers and controls dwell time, and fail-safe anomaly detection for high-density platforms.

  • Embedded Systems
  • Sensor Fusion
  • QR / RFID
  • Load Sensing
  • Anomaly Detection
  • Distributed Systems
Hardware · Firmware

ATmega328P Custom Development Board

The problem

Off-the-shelf boards hide how a microcontroller system is put together. Building one from scratch exposes what firmware depends on: the clock, the programming interface and the I/O.

How it works

  1. An ATmega328P, the chip inside the Arduino Uno, sits at the centre
  2. A crystal oscillator gives it an accurate clock
  3. A TTL interface uploads firmware from a computer
  4. Multiple I/O ports connect sensors and modules

What I built

The board in KiCad from schematic to PCB layout, the I/O ports for sensor interfacing, and its validation through hardware bring-up and firmware testing.

  • ATmega328P
  • KiCad
  • PCB Design
  • Firmware
  • Microcontrollers
